# LiveShield Dependency Inventory

This inventory records the reproducible dependency baseline and its privacy impact. Versions here
must match the centralized Gradle configuration and the pinned local-development infrastructure.
Adding or upgrading a dependency requires another licence and data-flow review.

## Privacy boundary legend

- **Build only**: Runs on a developer or CI machine and is not packaged in the application.
- **On-device, raw zone**: May receive transient camera pixels inside LiveShield's bounded raw-frame
  boundary. It must not persist, log, or transmit those pixels.
- **On-device, metadata only**: Receives findings or configuration, not raw pixels.
- **On-device, sanitized zone**: Receives only renderer-produced sanitized video or encoded units.
- **Test only**: Runs only in tests and must use approved fixtures and privacy-safe results.
- **Local relay**: Runs outside the Android application and must receive only sanitized video.

## Explicit exclusions

- V1 has no microphone permission, audio capture dependency, audio encoder, audio packet type, or
  audio publication API.
- TikTok SDKs are not dependencies. TikTok integration uses only creator-issued external RTMP
  destination details, held for the active session and excluded from logs and metrics.
- Public datasets and later consented recordings are evaluation inputs, not application
  dependencies. Their licences, provenance, access controls, and deletion rules are maintained in
  the fixture manifests and test-data documentation.
- No analytics, crash-upload, cloud-vision, face-recognition, or biometric-embedding dependency is
  approved for V1. The previously declared ML Kit artifacts have been removed rather than treated
  as an exception; release dependency gates reject their telemetry and model-download groups.
